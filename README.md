# 상한가 음양음 스캐너

첨부 리포트의 매매 기법을 데이터 필터로 구현한 한국 주식 스캐너입니다.

## 판정 기준

1. 첫째 날: 종가가 전일 종가 대비 약 29.5% 이상 오른 상한가 후보
2. 둘째 날: 음봉, 종가는 첫째 날 종가보다 높음
3. 셋째 날: 양봉, 종가는 첫째 날 종가보다 높음
4. 넷째 날: 음봉, 종가는 첫째 날 종가보다 높음

넷째 날 일봉이 확정된 뒤 다음 거래일 오전 관심 종목으로 확인합니다.

## 실행

```powershell
pip install -r requirements.txt
python .\scanner.py
```

결과는 `reports/latest.md`에 저장됩니다.

## 매일 오전 8시 자동 실행

```powershell
.\install_daily_task.ps1
```

Windows 작업 스케줄러에 `KoreaStockPatternScanner` 작업이 등록됩니다. 매일 오전 8시에 `run_daily.ps1`이 실행되고, 결과 파일과 로그는 `reports` 폴더에 저장됩니다.

## 데이터 소스

일봉 데이터는 FinanceData의 `marcap` 공개 데이터셋을 사용합니다. 연도별 Parquet 파일은 `.cache/marcap` 아래에 자동 캐시됩니다.

## 주의

이 프로그램은 매매 추천이 아니라 사용자가 제공한 영상 기법에 맞는 종목을 자동 필터링하는 도구입니다. 악재, 거래정지, 투자경고/위험, 유동성, 시장 전체 흐름은 별도로 확인해야 합니다.
